## 区分"熟练工"与"工程师"

| 熟练工 | 工程师 |
|--------|--------|
| 会套用框架的 Demo | 能设计自己的架构 |
| 知道怎么用 | 知道为什么这么用 |
| 出了问题不知道怎么办 | 能系统性定位和修复 |
| 复制粘贴代码 | 封装接口、抽象层 |
| 只关注功能 | 关注可观测性、安全、成本 |

## STAR 法则回答模板

**问题**："请分享一个你在 Agent 开发中遇到的最大挑战。"

```
S - 背景：
  我在开发一个知识库问答 Agent 时，用户反馈模型经常给出不准确的答案。

T - 任务：
  我需要定位是检索问题还是模型幻觉。

A - 行动：
  1. 检查检索结果——BM25 和向量检索的相关度差异很大
  2. 分析 chunk_size——1500 Token 太大，包含多个主题
  3. 调整为 500 Token + 75 重叠，引入 CrossEncoder 重排序
  4. 在提示词中增加"仅基于以下知识回答"的约束

R - 结果：
  准确率从 65% 提升到 89%。我学到了：检索质量是 RAG 系统的生命线，
  分块策略需要通过评估来调优，而不是凭直觉。
```
