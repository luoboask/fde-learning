**核心发现：**
- 推理优化方向薪资透明且较高（30-40k+），要求底层技术栈（CUDA、量化、分布式）
- Agent 应用方向覆盖面广，淘天要求 TypeScript+React（偏前端），钉钉要求 Java/Python+Agent架构（偏后端）
- 科研院所（宁波数字孪生）给出明确薪资范围：硕士20万起、博士40万起
- 大厂（腾讯/字节/快手）推理岗明确要求 CUDA/Triton + vLLM 二次开发能力
- **跨境电商（Anker）也要求 CUDA 工程师**——说明 AI 推理优化已渗透传统行业

## 公司分析

### 互联网大厂

- **淘天集团**：Agent 应用方向，要求 TypeScript+React 前端能力 + LangGraph/RAG 等 Agent 技术，偏业务落地
- **腾讯**：两个方向——Omni全模态（算法研究）+ 推理性能优化（工程落地），均要求 Python/C++ 双栈
- **字节跳动**：校招岗明确要求 CUDA/Triton + vLLM/SGLang + 量化/稀疏化，应届生就要底层能力
- **滴滴**：高级/资深岗，C++/Python + CUDA + vLLM/TensorRT-LLM + 分布式，要求最全面
- **快手**：多模态推理方向，vLLM/SGLang + CUDA/Triton + 量化 + 芯片优化

### 科研院所

- **上海 AI Lab**：两个方向（深圳河套学院 + 浦东），覆盖系统研发和推理部署，要求 Python/C++ + vLLM/Megatron + CUDA + 分布式，同时要求顶会论文或开源贡献
- **公安部第一研究所**：推理优化方向，30-40k 薪资透明，PyTorch + vLLM/TensorRT + CUDA + 量化
- **宁波数字孪生（东方理工）**：明确薪资范围（硕士20万起/博士40万起），要求 PyTorch + RAG + Agent + EDA 领域知识

### 传统企业转型

- **海翼电子（Anker）**：跨境电商企业也要求 CUDA 工程师，TensorRT + ONNX + NPU/DSP 嵌入式部署，说明 AI 推理优化已全面渗透传统行业
- **平安健康保险**：保险行业也需要推理加速人才，vLLM/SGLang + PagedAttention + K8s + Docker，加分项要求 CUDA/Triton Kernel 开发

## 总结：2026 年 FDE 最应该学什么

精通 PyTorch + vLLM + SGLang + Python/C++ 工程能力，掌握 CUDA/Triton GPU 优化，能写 Agent 应用（LangGraph/RAG/Multi-Agent/Memory），知道 NPU/DSP 边缘部署是怎么回事——2026 年 FDE 市场基本通吃。大厂核心差距在 **GPU 底层编程能力（CUDA/Triton）**，科研院所和传统企业（Anker、数字孪生）也在加速抢人。
