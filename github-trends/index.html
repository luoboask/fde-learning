GitHub AI 项目趋势

基于 2025 年 12 月至 2026 年 6 月（半年）X/Twitter 社区讨论和 GitHub Trending 数据，整理最受欢迎的 AI/Agent 开源项目。

🔍 关键模式

1.Agent 工具生态正在超越模型本身 — 最佳 AI 工具不是替换开发者，而是修复 Agent 的短板
2.本周最大增长来自 .claude/.cursor 配置技能库（+19.7K），说明 Agent 工程化的核心是规则而非模型
3.垂直行业 Agent 正式爆发 — Anthropic 官方开源法律/金融 Agent 套件，不是 demo 而是生产级工作流
4.跨会话记忆（agentmemory）和知识图谱（codegraph）成为 AI 编程的两大刚需
5.免费模型路由层（25K+ stars）印证了 token 计费模式的脆弱性
6.可视化 Agent 编排（Flowise/dify）正在降低 Agent 开发门槛，23,300+ forks 说明社区活跃
7.可观测性平台（Langfuse）和 MCP 协议成为 2026 下半年生产部署的标配
